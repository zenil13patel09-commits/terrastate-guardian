ℹ️ How it works

  1. Select or create a project to organize your infrastructure
  2. Choose the environment (dev, staging, or prod)
  3. Upload your Terraform state JSON file
  4. The system will parse resources and detect drift automatically
  5. If this is the first upload for this project-environment, it becomes the baseline
  6. Subsequent uploads are compared against the baseline to detect drift

📋 State File Requirements

  • Must be a valid JSON file
  • Should be a Terraform state file (terraform.tfstate)
  • Supports Terraform 0.12+ format
  • Maximum file size: 10MB
